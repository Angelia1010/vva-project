# 分支说明

| 分支 | 用途 | 状态 |
|---|---|---|
| `feat/duties` | **单摄像头稳定版**：一路摄像头的全部功能，已在 4×3090 服务器上实测 | 现在生产使用这个 |
| `feat/multi-camera` | 在稳定版基础上增加**多岗位、多摄像头（最多 4 路）** | 新开发，待服务器实测 |
| `main` | 早期版本 | 不再更新 |

切换分支：

```bash
cd /data7/Vision-Voice-Agent/vva-project
git fetch origin
git checkout feat/duties          # 或 feat/multi-camera
git pull
sudo systemctl restart vva-app
```

两个分支用同一个数据库（`data/ops.db`）。从 `feat/duties` 切到 `feat/multi-camera` 会自动升级数据（原来的摄像头变成第一路，职责、告警原样保留）；**切回 `feat/duties` 也能正常运行**，只是多出来的摄像头、岗位不会被使用。

## feat/duties —— 单摄像头稳定版（已测试）

最新提交：`4ad3cd4 产品更名为「春雷问鉴」，新 logo；「技能」改名「自学习」`

### 部署

- 4 张 RTX 3090：Qwen3.6-35B-A3B-FP8 用 0、1 号卡（张量并行 2），语音识别 2 号卡，语音合成 3 号卡。
- 必须带 `--max-num-seqs 16`；对话时关闭思考。
- 用 systemd 管理：`vva-vlm`、`vva-asr`、`vva-tts`、`vva-app` 四个服务。
- 网页：`https://<服务器>:9000`。

### 功能

**值守台（首页）**
- 三栏固定全屏：左边「我的职责」，中间实时画面和画面时间线，右边「待处理告警」和「指令」。
- 按笔记本屏幕（约 1260×660）排过版。
- 支持浏览器摄像头推流、服务器摄像头（RTSP / USB）。
- 浏览器麦克风语音对话，现场喇叭播报回答和告警。
- 「打断」「清空对话」两个文字按钮。

**职责**
- 三类职责：
  - 盯守：发生就通知；
  - 巡检：到点检查，异常才通知；
  - 汇报：到点发报告。
- 每条职责显示三要素：行为名称、处置动作（发钉钉、现场喇叭等）、职责期限（每天、工作日、截止到某天几点）。
- 一句话生成职责、行业模板、「试一下」（用当前画面检查一次，不发通知）。
- 值班员可以用语音或钉钉下达临时任务，默认当天有效。
- 命中后先放大复核再告警；冷却时间、持续多久才算、试运行（只记录不通知）。
- 告警标成误报时，可以把截图作为「不算」的例子，下次复核时参考。

**告警中心**
- 告警列表带截图、判断依据、处理经过（通知了谁、是否送达、谁在什么时候怎么处理的）。
- 可标记已处理、处理中、误报；单条删除。
- 统计：今日告警、待处理、本周误报率、平均响应时间。

**执行**
- 带编号的现场动作：01 喇叭喊话、02 通知值班群、03 抓拍存证可直接用。
- 04～09（声光报警、拨打值班电话、打开照明、锁闭门禁、关闭电源、设备急停）填上现场网关的 HTTP 地址后可用。
- 对值守台说「执行 3 号」即可；高风险动作要二次确认。

**通知**
- 钉钉：Stream 模式，群里 @机器人 对话；告警推送到默认告警群或指定群；定时报告。
- 飞书：同上。

**自学习、知识库、长期记忆**
- 自学习（原「技能」）：教它认识特定目标（参考图、判断标准、规则模板、热词）。
- 知识库：上传规章、规程、手册，回答时引用。
- 长期记忆：画面记录、提醒、指令按时间保存，可问「上午 9 点发生了什么」；可记备忘。

**其他**
- 产品名「春雷问鉴」和 logo。
- 自检脚本 `scripts/check_duties.py`：排查「看到了却没推钉钉」这类问题。

### 已知限制

- 只有一路摄像头、一个岗位。
- 视觉大模型的调用不排队：用户提问时后台观察会让出一个周期。

## feat/multi-camera —— 多岗位、多摄像头

在 `feat/duties` 全部功能的基础上：

- **岗位与摄像头**
  - 可以有多个岗位（如「1 号仓库」「2 号车间」），每个岗位下接多路摄像头（不同角度），总数默认最多 4 路。
  - 在「设置 → 岗位与摄像头」里增删，不用重启。
  - 填 RTSP 地址时可以「测试连接」，直接看到一帧画面；密码在网页上显示为 `******`。
- **值守台**
  - 画面上方是摄像头切换条，每路显示在线状态和待处理告警数。
  - 「四宫格」一屏看 4 路，点一格回到单画面。
  - 浏览器摄像头推流推到选中的那一路。
- **职责**
  - 新增「摄像头」选项：不选为全部摄像头，也可以只盯某几路。
  - 冷却、持续计时、复核都按「职责 + 摄像头」分开算：大门有人吸烟和仓库里有人吸烟各报各的。
  - 巡检到点后每一路各查一次。
- **告警**
  - 记录是哪个岗位、哪一路，截图取自那一路。
  - 钉钉、飞书消息标题写明「1 号仓库·大门」。
  - 告警中心可以按摄像头筛选。
  - 网络摄像头断开超过 2 分钟会发一条「摄像头离线」告警，恢复后记进处理经过。
- **对话**
  - 看画面、回看、定位都可以指定摄像头（「看一下装卸区」「2 号现在几个人」）。
  - 网页上没指定时，默认看值守台正在看的那一路。
  - 钉钉里没指定、又有多路时，它会先反问看哪一路。
  - 「各处现在有几个人」会逐路看完一起回答。
- **调度**：所有视觉大模型调用统一排队，优先级依次是用户提问、告警复核、职责检查、画面时间线，同时调用数默认上限 6。
- **兼容**：不改配置也能用，原来的单摄像头自动变成第一路（编号 `cam0`）。
