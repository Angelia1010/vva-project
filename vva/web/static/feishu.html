配置步骤
  1. 打开 飞书开放平台，创建企业自建应用，复制 App ID 和 App Secret 填到左边。
  2. “添加应用能力”里添加机器人。
  3. “权限管理”开通：im:message、im:message.group_at_msg:readonly、im:message.p2p_msg:readonly、im:message:send_as_bot、im:resource。
  4. 回到这里打开“开启飞书接入”，点“保存并生效”。
  5. “事件与回调”里订阅方式选使用长连接接收事件，添加事件“接收消息 im.message.receive_v1”。服务要先开启，否则保存不了。
  6. “版本管理与发布”创建版本并发布。
  7. 把机器人拉进群，在群里 @它 说句话，群会出现在“最近的消息”里，一键设为告警群。
