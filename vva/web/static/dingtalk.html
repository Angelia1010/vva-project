配置步骤
  1. 打开 钉钉开放平台，在“应用开发”里创建企业内部应用，在“凭证与基础信息”复制 Client ID 和 Client Secret 填到左边。
  2. “添加应用能力”里添加机器人，填写机器人名称、简介，消息接收模式选 Stream 模式，保存。
  3. “权限管理”开通：企业内机器人发送消息权限（qyapi_robot_sendmsg）、机器人下载文件（Robot.File.Download，接收语音用）。
  4. “版本管理与发布”创建版本并发布，可见范围选需要使用的人。
  5. 回到这里打开“开启钉钉接入”，点“保存并生效”，状态显示“运行中”即连上了。
  6. 私聊机器人，或在群设置“机器人”里添加这个机器人后在群里 @它 说句话，会话会出现在“最近的消息”里，一键设为告警群。
